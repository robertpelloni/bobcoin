# Bobcoin Showcase Script

This script outlines the flow for demonstrating the Bobcoin ecosystem in a 2-minute video or live demo.

## Scene 1: The Hook (30s)
*   **Visual:** Show the **Dashboard** in Dark Mode (Cyberpunk Theme).
*   **Action:** Enter the **Konami Code** (Up, Up, Down, Down, Left, Right, Left, Right, B, A).
*   **Effect:** Theme switches to "God Mode" (Purple/Gold), demonstrating the hidden easter egg.
*   **Narrative:** "Welcome to Bobcoin, the arcade protocol where gaming is mining."

## Scene 2: The Gameplay (30s)
*   **Visual:** Switch to **Rhythm Game**.
*   **Action:** Click **START MINING**. Play for 10 seconds, hitting notes (synths play).
*   **Action:** Click **AUTO / VISUALIZER**.
*   **Effect:** The game plays itself perfectly.
*   **Narrative:** "Proof of Play generates zk-SNARKs. Or use the visualizer mode for your idle arcade cabinet."

## Scene 3: The Infrastructure (30s)
*   **Visual:** Navigate to **System Status** (`/system`).
*   **Highlight:** Show the live **Block Lattice** stream and TPS counter.
*   **Visual:** Navigate to **Supernode** (`/supernode`).
*   **Highlight:** Hover over the **Peer Map** to show connected nodes.
*   **Action:** Add a Magnet Link (e.g., `magnet:?xt=urn:btih:sintel`) to start seeding.
*   **Narrative:** "Real P2P storage mining powered by WebTorrent. Seeding data earns validator rights."

## Scene 4: Mobile & Ecosystem (30s)
*   **Visual:** Show the **Architecture** page (`/architecture`).
*   **Overlay:** Show the **Mobile App** (React Native simulator) running side-by-side.
*   **Action:** Tap "Start Mining" on mobile. Watch the Hashrate graph spike.
*   **Narrative:** "A complete ecosystem: Web, Mobile, and P2P Storage working in harmony."

## Closing
*   **Visual:** **Explorer** page showing the transactions generated during the demo.
*   **Narrative:** "Bobcoin v2.1. Ready for the Arcade."
